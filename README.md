# Mijine Bar / Mijine 的收银台

一个原生 macOS 响应式桌面 demo：使用蟹堡王收银台壁纸，每次按下实体键盘按键，收银机金额增加 `0.01`。

App 启动时会把内置图片设置为 macOS 原生系统壁纸，再在桌面层实时绘制收银机金额。退出 App 时不会恢复之前的系统壁纸。

## 运行

在终端进入本目录后执行：

```bash
./scripts/run-app.sh
```

首次运行时，macOS 会请求“输入监控”权限。允许后，点击菜单栏中的键盘图标，选择“重新检查权限并启动”。部分系统版本可能要求退出并重新打开应用。

## 当前范围

- 原生 Swift、AppKit 和 Core Graphics，无第三方依赖
- 只读监听键盘，不拦截、不修改、不保存具体输入内容
- 每次实体按键增加 `0.01`，忽略长按产生的系统自动连发
- 金额按本地日期保存，应用重启后继续，并在每天本地时间零点归零
- 数字使用七段数码管效果并贴合壁纸中的收银机屏幕
- 收银员的双眼会看向鼠标指针；鼠标静止 6 秒后，瞳孔会平滑回到正中
- 使用参考猫咪制作的 Q 版橘猫作为 App 图标，顶部菜单栏使用自动适配明暗模式的小鱼干图标
- 菜单栏可选择固定增量预设、自定义固定金额，或在 `0.01～1.00` 内设置随机金额范围
- 菜单栏可立即清空金额，也可以关闭或开启每天零点自动清零
- 桌面图标下方显示，并支持多显示器和多个 Spaces
- 启动时自动给所有已连接显示器应用同一张原生系统壁纸，插入显示器后也会重新应用
- 菜单栏提供权限重试、打开系统设置、刷新窗口和退出

构建结果位于 `dist/Mijine Bar.app`。

构建脚本会自动使用钥匙串中的 `Apple Development` 证书。若机器上没有可用开发证书，则回退到临时签名。也可以通过 `PALLER_SIGN_IDENTITY` 指定证书名称。
